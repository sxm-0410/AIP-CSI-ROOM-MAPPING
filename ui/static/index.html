How it works: the ESP32 measures the router's Wi-Fi signal ~10×/s (strength) and ~50×/s (per-subcarrier channel state, CSI). It first learns what the empty path looks like. A person or object crossing the path changes the signal; when the variation or the level shift exceeds the learned limit the path is flagged. To re-learn the empty path, press the EN button on the board and keep the path clear for ~12 s.
